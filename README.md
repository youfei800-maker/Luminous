# Luminous

女性一人ひとりのキャリアと人生のストーリーに出会うメディア。
参照サイトのワイン色・淡いピンク・クリーム色と、`Bloom your future` のビジュアルを引き継いだ Next.js プロジェクトです。

## 構成

- Next.js 16 / React 19
- JavaScript（TypeScript なし）
- App Router（ルート直下の `app/`）
- Tailwind CSS 4（公式テンプレートの Turbopack プラグイン）
- ESLint なし、`src/` なし、import エイリアスは `@/*`
- ローカル開発は外部サービス不要。Vercelで公開する場合はSupabaseにデータと画像を保存
- 編集ページは編集者アカウントの初回設定またはMacからの移行が必要

## Vercelで公開・編集する

**[Vercel・Supabase接続とMacデータ移行の手順](docs/vercel-supabase.md)** を参照してください。Macだけに保存した編集内容は公開サイトへ自動転送されません。同じSupabaseプロジェクトに接続すると、公開サイトの `/editorial/login` から編集して反映できます。

## 開発

Node.js 20.9 以上が必要です。クラウド環境で検証したバージョンは Node.js 24.19.0 / npm 11.9.0 です。

```bash
cd /workspace/Luminous
npm ci --cache /tmp/luminous-npm-cache --no-audit --no-fund
npm run dev -- --hostname 0.0.0.0
```

既定ポートは 3000。使用中なら Next.js が 3001 以降の空きポートを選びます。実際のポートは起動ログで確認してください。

```bash
npm run build
npm start
```

## ページと機能

- `/` — トップ、ストーリー一覧、Girls / Women、メディアのビジョン、イベント案内
- `/stories` — 名前・職業・キーワード検索、カテゴリ・テーマの絞り込み
- `/girls` / `/women` — 対象カテゴリの一覧（世代をつなぐ対談は両方に表示）
- `/stories/[slug]` — インタビュー、人物プロフィール、キャリア年表、関連記事、共有
- `/saved` — ブックマークした記事。ログイン不要で、このブラウザの localStorage に保存
- `/about` — Luminous のビジョン・価値観
- `/events` / `/events/[slug]` — 公開イベント一覧、開催概要、申し込みフォームへのリンク
- `/activities` / `/activities/[slug]` — 公開した活動実績の一覧・詳細
- `/editorial/login` — 同じサイト内の編集部ログイン
- `/editorial` — 記事編集、下書き・公開管理、画像アップロード、トップ画像・ビジョンの設定、イベント・活動実績の管理

ヘッダーの虫眼鏡から全記事を検索できます。スマートフォン向けのメニュー、キーボード操作、Esc で閉じる検索ダイアログ、空の検索結果と404ページにも対応しています。

## コンテンツを変更する

### 編集ページを使う

Mac で既に取得済みのプロジェクトを更新する場合は、そのフォルダで実行します。

```bash
git pull
npm ci
npm run editorial:setup
npm run dev
```

初回設定ではメールアドレスと12文字以上のパスワードを入力します。パスワード入力中は文字が表示されません。起動後、同じサイトの `/editorial/login` を開いてログインしてください。編集者は1アカウントです。忘れた場合はサーバーのターミナルで `npm run editorial:setup -- --reset` を実行します。再設定すると既存のログインは無効になります。

編集ページで記事・人物プロフィール・本文・キャリア年表を編集できます。画像は JPEG / PNG / WebP（4MB以下）をアップロードでき、WebP に変換して保存します。下書き保存では公開済みの内容は変わりません。「公開する」で公開サイトへ反映し、「非公開にする」で一覧と記事ページから取り下げます。公開中の記事は、非公開にしてから削除できます。別の画面で同じ記事を先に保存した場合は、上書きを防ぐため再読み込みが必要です。

「サイト設定」からトップの見出し・説明文・ビジョンを変更できます。編集画面のプレビューは未保存の内容も確認できます。公開ページは動的に読み込み、公開後はページの再読み込みで更新内容を表示します。

最初の6記事は `lib/stories.js` の架空のサンプルです。公開用の取材記事・画像に差し替え、「サンプル記事」のチェックを外してください。初期データが保存された後は、編集画面から変更してください。

### トップ画像・イベント・活動実績を管理する

「サイト設定」でトップページ画像を選択・アップロードできます。画像の説明と表示位置（中央・上・下）を設定し、「サイト設定を保存」で反映します。

「イベント管理」の「新しいイベント」から、開催日・時間・会場・参加条件・主催・本文・画像を入力できます。申し込みフォームの HTTPS URL とボタンの文言を設定し、受付状態を「受付中」にすると申し込みボタンを表示します。「受付開始前」「受付終了」ではボタンを表示しません。申込内容の受付・保存はリンク先のフォームで行います。サイト内で参加者情報は保存しません。

「活動実績管理」の「新しい活動実績」から、活動日・カテゴリ・連携先・概要・本文・成果・画像を掲載できます。架空の実績は初期掲載せず、実際の活動を登録して公開します。

イベントと活動実績も、下書き保存・プレビュー・公開・非公開・削除に対応します。下書きは公開一覧にも詳細URLにも表示しません。公開中のページを削除するには、先に非公開にします。保存後のページURLは固定です。イベント一覧は `/events`、活動実績一覧は `/activities` で、ヘッダー・フッターから開けます。トップのイベント案内も公開イベントから表示するため、すべて非公開・削除すると表示されません。

既存の `.luminous/content.json` はそのまま使用できます。初めて新機能を開くとトップ画像・既存イベントの初期値を補完し、保存時に追記します。既存の記事・サイト設定・アカウントは維持します。既にイベントを全件削除して保存した場合は初期イベントを再生成しません。

Macで更新する際は、開発サーバーを実行しているターミナルで **Control + C** を押し、次を1行ずつ実行してください。アカウントの再設定は不要です。

```bash
cd ~/Luminous
git pull
npm ci
npm run dev
```

### 保存先と公開運用

外部接続を設定していないローカル環境では、記事・設定・画像・編集者アカウントを既定でプロジェクト内の `.luminous/` に保存します。このフォルダは Git 管理の対象外で、GitHubへのpushには含まれません。アカウントにはパスワードのハッシュとセッション署名用の秘密鍵を保存します。バックアップはフォルダ全体を非公開の場所に保存してください。

Vercelでは、Supabaseに接続してデータ・画像・アカウントを永続保存します。`SUPABASE_URL`（または `NEXT_PUBLIC_SUPABASE_URL`）と、サーバー専用の `SUPABASE_SERVICE_ROLE_KEY`（または `SUPABASE_SECRET_KEY`）を設定します。未設定のVercelでは初期の公開ページを表示し、編集は無効にします。書き込み失敗時にローカル保存へ切り替えることはありません。

ローカルのファイル保存方式で公開運用する場合は、HTTPS・書き込み可能な永続ディスク・単一のNode.jsサーバープロセスが必要です。保存先は `LUMINOUS_DATA_DIR` で指定できます。

### 検証

```bash
npm run build
npm run test:editorial
```

認証、下書き・公開・非公開、再起動後の保存、同時編集の競合、設定変更、画像検証、パスワード再設定を、一時的なテスト用保存先で検証します。実際の編集データは変更しません。

色・余白・レスポンシブ表示は `app/globals.css`、トップ構成は `app/page.js` で編集できます。
